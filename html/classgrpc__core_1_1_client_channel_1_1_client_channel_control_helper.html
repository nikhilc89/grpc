◆ GetUnsafeChannelCredentials()

RefCountedPtr< grpc_channel_credentials > grpc_core::ClientChannel::ClientChannelControlHelper::GetUnsafeChannelCredentials ( )
inlineoverridevirtual

Returns the UNSAFE ChannelCredentials used to construct the channel, including bearer tokens. LB policies should generally have no use for these credentials, and use of them is heavily discouraged. These must be used VERY carefully to avoid sending bearer tokens to untrusted servers, as the server could then impersonate the client. Generally, it is safe to use these credentials only when communicating with the backends.

Implements grpc_core::LoadBalancingPolicy::ChannelControlHelper.
