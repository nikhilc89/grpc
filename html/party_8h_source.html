46// Terms Used:
47//
48// Concurrent promises: Promises that may be in progress at a given instant
49// of time, but they may or may not execute simultaneously.
50// Parallel promises: Two or more Promises that are getting executed
51// simultaneously at the same instant of time.
52//
53// Promise Party
54// A Promise Party forms the execution environment for Promises. It runs up
55// to sixteen concurrent party participants and ensures none of the participants
56// run in parallel with each other.
57//
58// Party Participant
59// One Promise Party has 16 Participant slots. Each Participant slot can hold
60// one of the three
61// 1. A Promise
62// 2. Or a Promise Factory
63// 3. or any type of Participant object, such as SpawnSerializer.
64//
65// Using a Party
66// A party should be used when
67// 1. You need many promises to be run in a way that is concurrent but not
68// parallel.
69// 2. These promises have their own complex sleep and wake mechanisms.
70// 3. You need a way to run the pending promises to completion by repolling them
71// as needed.
72//
73// Creating a new Party
74// A Party must only be created using Party::Make function.
75//
76// Spawning a promise on a Party
77// 1. A promise can be spawned on a party using either Spawn or SpawnWaitable
78// method.
79// 2. If you want to bulk spawn promises on a party before any thread
80// starts executing them, use Party::WakeupHold.
81//
82// Execution of Spawned Promises
83// A Participant spawned on a party will get executed by that party.
84// Whenever the party wakes up, it will execute all unresolved Party
85// Participants at least once. After any Party Participant is resolved, its slot
86// is freed up to make place for new participants.
87//
88// When these Party Participants are executed (polled), they can either
89// 1. Resolve by returning a value
90// 2. Return Pending{}
91// 3. Wait for a certain event to happen using either a Notification or a Latch.
92//
93// When a promise factory is passed as a Party Participant, the promise factory
94// is used to generate the promise once, and then the promise is executed once
95// each time the party is polled till it resolves.
96//
97// Sleep mechanism of a Party
98// A party will Sleep/Quiece if all Participants Spawned on the party are in any
99// of the following states
100// 1. Return Pending{}
101// 2. Resolve
102// 3. Are waiting because of a Latch.
103// If a party is currently running a Participant, it is said to be active/awake.
104// Otherwise it is said to be Sleeping or Quieced.
105//
106// Wake mechanism of a Party
107// To wake up a sleeping party you can use the Waker object. Once the Party is
108// woken, it will be executed as mentioned above.
109//
110// Party Cancellation
111// A Party can be cancelled using party_.reset() method.
112//
113// Guarantees of a Party
114// 1. All Participant spawned on one party are guaranteed to be run serially.
115// Their execution will not happen in parallel.
116// 2. If a promise is executed, its on_complete is guaranteed to be executed as
117// long as the party is not cancelled.
118// 3. Once a party is cancelled, Participants that were Spawned onto the party,
119// but not yet executed, will not get executed.
120// 4. Promise spawned on a party will never be repolled after it is resolved.
121// 5. A promise spawned on a party, can in turn spawn another promise either on
122// the same party or on another party. We allow nesting of Spawn function.
123// 6. A promise or promise factory that is passed to a Spawn function could
124// either be a single simple promise, or it could be a promise combinator such
125// as TrySeq, TryJoin, Loop or any such promise combinator. Nesting of these
126// promise combinators is allowed.
127// 7. You can re-use the same party to spawn new Participants as long as the
128// older Participants have been resolved.
129// 8. We guarantee safe working of up to 16 un-resolved participants
130// on a party at a time.
131//
132// Non-Guarantees of a Party
133// 1. Promises spawned on one party are not guaranteed to execute in the same
134// order. They can execute in any order. If you need the promises to be executed
135// in a specific order, use a SpawnSerializer. If that is not feasible for some
136// reason, then either consider the use of a promise combinator, or order the
137// execution of promises using Notifications or Latches.
138// 2. A party cannot guarantee which thread a party Participant will execute on.
139// It could either execute on the current thread, or an event engine thread or
140// any other thread.
141// 3. Say, we spawned promises P1_1, P1_2, P1_3 on party1. Then promise P1_1 in
142// turn spawns promise P2_1, P2_2, P2_3 on party2. In such cases, party1 and
143// party2 may either execute on the same thread, or they may both execute on
144// different threads. party1 and party2 may or may not run in parallel.

190 // When calling into a Party from outside the promises system we often would
191 // like to perform more than one action.
192 // This class tries to acquire the party lock just once - if it succeeds then
193 // it runs the party in its destructor, effectively holding all wakeups of the
194 // party until it goes out of scope.
195 // If it fails, presumably some other thread holds the lock - and in this case
196 // we don't attempt to do any buffering.
197 class WakeupHold {
198 public:
199 WakeupHold() = default;
200 explicit WakeupHold(Party* party)
201 : prev_state_(party->state_.load(std::memory_order_relaxed)) {
202 // Try to lock
203 if ((prev_state_ & kLocked) == 0 &&
204 party->state_.compare_exchange_weak(prev_state_,
205 (prev_state_ | kLocked) + kOneRef,
206 std::memory_order_relaxed)) {
207 DCHECK_EQ(prev_state_ & ~(kRefMask | kAllocatedMask), 0u)
208 << "Party should have contained no wakeups on lock";
209 // If we win, record that fact for the destructor
210 party->LogStateChange("WakeupHold", prev_state_,
211 (prev_state_ | kLocked) + kOneRef);
212 party_ = party;
213 }
214 }
215 WakeupHold(const WakeupHold&) = delete;
216 WakeupHold& operator=(const WakeupHold&) = delete;
217 WakeupHold(WakeupHold&& other) noexcept
218 : party_(std::exchange(other.party_, nullptr)),
219 prev_state_(other.prev_state_) {}
220 WakeupHold& operator=(WakeupHold&& other) noexcept {
221 std::swap(party_, other.party_);
222 std::swap(prev_state_, other.prev_state_);
223 return *this;
224 }
225
226 ~WakeupHold() {
227 if (party_ == nullptr) return;
228 party_->RunLockedAndUnref(party_, prev_state_);
229 }
230
231 private:
232 Party* party_ = nullptr;
233 uint64_t prev_state_;
234 };

236 // SpawnSerializer is a helper class to serialize the execution of multiple
237 // promises on a party.
238 //
239 // Provides the guarantee that given:
240 // SpawnSerializer* serializer = party->MakeSpawnSerializer();
241 // serializer->Spawn([] { /* promise 1 */; });
242 // serializer->Spawn([] { /* promise 2 */; });
243 // 1. promise 1 will be resolved before promise 2 is started.
244 // 2. promise 1 and promise 2 will execute on `party`.
245 //
246 // It's possible to have multiple SpawnSerializer instances on a party.
247 // Once created, the SpawnSerializer is only valid until the party is
248 // released - note that SpawnSerializer itself does not hold a ref to the
249 // party.
250 //
251 // Each SpawnSerializer consumes one slot in the party's participant array for
252 // the lifetime of the party - that is that a SpawnSerializer counts as one of
253 // the sixteen promises executing on a Party.
254 //
255 // The promises spawned by SpawnSerializer *DO NOT* count towards the sixteen
256 // promise limit.
257 //
258 // The size of this type matters, and so we leverage private inheritance to
259 // minimize the number of pointers needed to be kept per instance.
260 class SpawnSerializer final : private Participant {
261 public:
262 // Spawn a promise into the party.
263 //
264 // The promise will be polled until it is resolved, or until the party is
265 // shut down.
266 //
267 // Later promises spawned by this serializer will not be polled until this
268 // promise is resolved, and then one at a time in the order they were
269 // spawned.
270 //
271 // Spawn itself is not thread safe: at most one thread can call Spawn at a
272 // time. Just as the execution of promises is serialized by this type, the
273 // spawning of promises is expected to be serialized by some external entity
274 // (usually this is a Seq running on a different party).
275 template <class Factory>
276 void Spawn(Factory factory) {
277 auto empty_completion = [](Empty) {};
278 next_.Push(new ParticipantImpl<Factory, decltype(empty_completion)>(
279 "SpawnSerializer", std::move(factory), empty_completion));
280 party_->WakeupFromState<false>(
281 party_->state_.load(std::memory_order_relaxed), wakeup_mask_);
282 }

285 friend class Party;
286 friend class Arena;

288 bool PollParticipantPromise() override;
289 void Destroy() override;

291 explicit SpawnSerializer(Party* party)
292 : next_(party->arena()), party_(party) {}

294 // Queue of promises to be executed after the active promise resolves.
295 ArenaSpsc<Participant*, false> next_;
296 // The promise currently being executed.
297 Participant* active_ = nullptr;
298 // The wakeup mask for this serializers participant.
299 // Allows us to wake up the party when a new promise is added to the queue.
300 WakeupMask wakeup_mask_;
301 // The party this serializer is running on.
302 Party* const party_;
303 };

305 // Spawn one promise into the party.
306 // The party can poll the promise until it is resolved, or until the party is
307 // shut down.
308 // The on_complete callback will be called with the result of the
309 // promise if it completes. Even if the promise returns a failed status,
310 // on_complete will be called.
311 // promise_factory called to create the promise with the party lock taken;
312 // after the promise is created the factory is destroyed. This means that
313 // pointers or references to factory members will be invalidated after the
314 // promise is created - so the promise should not retain any of these.
315 // This function is thread safe. We can Spawn different promises onto the
316 // same party from different threads.
317 // A party can hold upto 16 unresolved promises at a time. However, this
318 // number might change in the future.
319 template <typename Factory, typename OnComplete>
320 void Spawn(absl::string_view name, Factory promise_factory,
321 OnComplete on_complete);

338 GPR_ATTRIBUTE_ALWAYS_INLINE_FUNCTION void IncrementRefCount() {
339 const uint64_t prev_state =
340 state_.fetch_add(kOneRef, std::memory_order_relaxed);
341 LogStateChange("IncrementRefCount", prev_state, prev_state + kOneRef);
342 }
343 GPR_ATTRIBUTE_ALWAYS_INLINE_FUNCTION void Unref() {
344 uint64_t prev_state = state_.fetch_sub(kOneRef, std::memory_order_acq_rel);
345 LogStateChange("Unref", prev_state, prev_state - kOneRef);
346 if ((prev_state & kRefMask) == kOneRef) PartyIsOver();
347 }

390 template <typename SuppliedFactory, typename OnComplete>
391 class ParticipantImpl final : public Participant {
392 using Factory = promise_detail::OncePromiseFactory<void, SuppliedFactory>;
393 using Promise = typename Factory::Promise;
394
395 public:
396 ParticipantImpl(absl::string_view, SuppliedFactory promise_factory,
397 OnComplete on_complete)
398 : on_complete_(std::move(on_complete)) {
399 Construct(&factory_, std::move(promise_factory));
400 }
401 ~ParticipantImpl() {
402 if (!started_) {
403 Destruct(&factory_);
404 } else {
405 Destruct(&promise_);
406 }
407 }
408
409 bool PollParticipantPromise() override {
410 if (!started_) {
411 auto p = factory_.Make();
412 Destruct(&factory_);
413 Construct(&promise_, std::move(p));
414 started_ = true;
415 }
416 auto p = promise_();
417 if (auto* r = p.value_if_ready()) {
418 on_complete_(std::move(*r));
419 delete this;
420 return true;
421 }
422 return false;
423 }
424
425 void Destroy() override { delete this; }

430 GPR_NO_UNIQUE_ADDRESS Promise promise_;
431 };
432 GPR_NO_UNIQUE_ADDRESS OnComplete on_complete_;
433 bool started_ = false;
434 };

436 template <typename SuppliedFactory>
437 class PromiseParticipantImpl final
438 : public RefCounted<PromiseParticipantImpl<SuppliedFactory>,
439 NonPolymorphicRefCount>,
440 public Participant {
441 using Factory = promise_detail::OncePromiseFactory<void, SuppliedFactory>;
442 using Promise = typename Factory::Promise;
443 using Result = typename Promise::Result;
444
445 public:
446 PromiseParticipantImpl(absl::string_view, SuppliedFactory promise_factory) {
447 Construct(&factory_, std::move(promise_factory));
448 }
449
450 ~PromiseParticipantImpl() {
451 switch (state_.load(std::memory_order_acquire)) {
452 case State::kFactory:
453 Destruct(&factory_);
454 break;
455 case State::kPromise:
456 Destruct(&promise_);
457 break;
458 case State::kResult:
459 Destruct(&result_);
460 break;
461 }
462 }
463
464 // Inside party poll: drive from factory -> promise -> result
465 bool PollParticipantPromise() override {
466 switch (state_.load(std::memory_order_relaxed)) {
467 case State::kFactory: {
468 auto p = factory_.Make();
469 Destruct(&factory_);
470 Construct(&promise_, std::move(p));
471 state_.store(State::kPromise, std::memory_order_relaxed);
472 }
473 [[fallthrough]];
474 case State::kPromise: {
475 auto p = promise_();
476 if (auto* r = p.value_if_ready()) {
477 Destruct(&promise_);
478 Construct(&result_, std::move(*r));
479 state_.store(State::kResult, std::memory_order_release);
480 waiter_.Wakeup();
481 this->Unref();
482 return true;
483 }
484 return false;
485 }
486 case State::kResult:
487 Crash(
488 "unreachable: promises should not be repolled after completion");
489 }
490 }
491
492 // Outside party poll: check whether the spawning party has completed this
493 // promise.
494 Poll<Result> PollCompletion() {
495 switch (state_.load(std::memory_order_acquire)) {
496 case State::kFactory:
497 case State::kPromise:
498 return Pending{};
499 case State::kResult:
500 return std::move(result_);
501 }
502 }
503
504 void Destroy() override { this->Unref(); }

506 private:
507 enum class State : uint8_t { kFactory, kPromise, kResult };
508 union {
509 GPR_NO_UNIQUE_ADDRESS Factory factory_;
510 GPR_NO_UNIQUE_ADDRESS Promise promise_;
511 GPR_NO_UNIQUE_ADDRESS Result result_;
512 };
513 Waker waiter_{GetContext<Activity>()->MakeOwningWaker()};
514 std::atomic<State> state_{State::kFactory};
515 };

517 // State bits:
518 // The atomic state_ field is composed of the following:
519 // - 24 bits for ref counts
520 // 1 is owned by the party prior to Orphan()
521 // All others are owned by owning wakers
522 // - 1 bit to indicate whether the party is locked
523 // The first thread to set this owns the party until it is unlocked
524 // That thread will run the main loop until no further work needs to
525 // be done.
526 // - 1 bit to indicate whether there are participants waiting to be
527 // added
528 // - 16 bits, one per participant, indicating which participants have
529 // been
530 // woken up and should be polled next time the main loop runs.
531
532 // clang-format off
533 // Bits used to store 16 bits of wakeups
534 static constexpr uint64_t kWakeupMask = 0x0000'0000'0000'ffff;
535 // Bits used to store 16 bits of allocated participant slots.
536 static constexpr uint64_t kAllocatedMask = 0x0000'0000'ffff'0000;
537 // Bit indicating locked or not
538 static constexpr uint64_t kLocked = 0x0000'0008'0000'0000;
539 // Bits used to store 24 bits of ref counts
540 static constexpr uint64_t kRefMask = 0xffff'ff00'0000'0000;
541 // clang-format on
542
543 // Shift to get from a participant mask to an allocated mask.
544 static constexpr size_t kAllocatedShift = 16;
545 // How far to shift to get the refcount
546 static constexpr size_t kRefShift = 40;
547 // One ref count
548 static constexpr uint64_t kOneRef = 1ull << kRefShift;

561 // Wakeable implementation
562 void Wakeup(WakeupMask wakeup_mask) final {
563 GRPC_LATENT_SEE_INNER_SCOPE("Party::Wakeup");
564 if (Activity::current() == this) {
565 wakeup_mask_ |= wakeup_mask;
566 Unref();
567 return;
568 }
569 WakeupFromState<true>(state_.load(std::memory_order_relaxed), wakeup_mask);
570 }

572 template <bool kReffed>
573 GPR_ATTRIBUTE_ALWAYS_INLINE_FUNCTION void WakeupFromState(
574 uint64_t cur_state, WakeupMask wakeup_mask) {
575 GRPC_LATENT_SEE_INNER_SCOPE("Party::WakeupFromState");
576 DCHECK_NE(wakeup_mask & kWakeupMask, 0u)
577 << "Wakeup mask must be non-zero: " << wakeup_mask;
578 while (true) {
579 if (cur_state & kLocked) {
580 // If the party is locked, we need to set the wakeup bits, and then
581 // we'll immediately unref. Since something is running this should never
582 // bring the refcount to zero.
583 if (kReffed) {
584 DCHECK_GT(cur_state & kRefMask, kOneRef);
585 } else {
586 DCHECK_GE(cur_state & kRefMask, kOneRef);
587 }
588 const uint64_t new_state =
589 (cur_state | wakeup_mask) - (kReffed ? kOneRef : 0);
590 if (state_.compare_exchange_weak(cur_state, new_state,
591 std::memory_order_release)) {
592 LogStateChange("Wakeup", cur_state, cur_state | wakeup_mask);
593 return;
594 }
595 } else {
596 // If the party is not locked, we need to lock it and run.
597 DCHECK_EQ(cur_state & kWakeupMask, 0u);
598 const uint64_t new_state =
599 (cur_state | kLocked) + (kReffed ? 0 : kOneRef);
600 if (state_.compare_exchange_weak(cur_state, new_state,
601 std::memory_order_acq_rel)) {
602 LogStateChange("WakeupAndRun", cur_state, new_state);
603 wakeup_mask_ |= wakeup_mask;
604 RunLockedAndUnref(this, cur_state);
605 return;
606 }
607 }
608 }
