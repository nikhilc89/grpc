Detailed Description

A proxy object implemented by the client channel and used by the LB policy to communicate with the channel.

◆ GetUnsafeChannelCredentials()

virtual RefCountedPtr< grpc_channel_credentials > grpc_core::LoadBalancingPolicy::ChannelControlHelper::GetUnsafeChannelCredentials ( )
pure virtual

Returns the UNSAFE ChannelCredentials used to construct the channel, including bearer tokens. LB policies should generally have no use for these credentials, and use of them is heavily discouraged. These must be used VERY carefully to avoid sending bearer tokens to untrusted servers, as the server could then impersonate the client. Generally, it is safe to use these credentials only when communicating with the backends.

Implemented in grpc_core::ClientChannel::ClientChannelControlHelper, grpc_core::ClientChannelFilter::ClientChannelControlHelper, and grpc_core::LoadBalancingPolicy::DelegatingChannelControlHelper.
